# Visual references: aesthetic only, NOT the V2 mechanism

- `cello_mode_upright_concept.png`: early studio concept of an upright electric-cello-like instrument.
- `bass_mode_horizontal_concept.png`: early studio concept of a bass-like horizontal string instrument.

**These are two different, mutually inconsistent concept images**, not a before/after transformation of one verified CAD model. They may show implausible string paths, body contours or supports. Do NOT build from their dimensions or promise those mechanisms work.

The V2 design is **one same core, same permanently deployed wing configuration for both live poses**. Only after performance do wing hinges fold to the core and the endpin stows. When rendering new images, show four states of the SAME actual assembly: upright-live, horizontal-live, mid-rotation sweep, packed-folded. The fixed bridge/string system never transforms.
